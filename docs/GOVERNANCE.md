# Governance (stub)

Full governance and funding are still open: ADR [0014](adr/README.md). This file holds only the commitments already decided.

## No feature gating, ever
OverCut will never put a feature behind a paywall, subscription, account, watermark, usage cap, or "pro" tier, in any build, on any platform. Costs are covered by staying a lean project with no servers, plus donations and sponsors. Optional services (if any) must have a local fallback and may not hold back a feature that works locally. Changing this commitment requires an accepted ADR that supersedes 0009 and a public announcement, not a code change. Related: `docs/PRODUCT.md` principle 1.

## Licence and contributions
Licence split and DCO sign-off (no CLA): [ADR 0009](adr/0009-license.md), `LICENSE`, `CONTRIBUTING.md`.
