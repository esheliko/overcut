# 0012 Name and trademark check
**Status**: **open: owner action** (blocks public launch, not development)

**Context.** The owner chose "Overcut". Names of media tools are crowded and a rename after launch is costly.

**Do before going public.** Search USPTO/EUIPO/WIPO (classes 9 and 42) and app stores for "Overcut" and near variants; check domain, GitHub org, npm/crates names, social handles; note existing products using "over-cut"/"overcut" in video or editing contexts (the term is also a general editing/cinema term). Decide: proceed, add a distinguishing mark (logo/wordmark), or rename. Reserve the handles and the crate/npm names either way.

**Recommendation.** Reserve handles now (cheap), run the trademark search before the M3 public beta, keep the name out of identifiers where practical (engine crates are `app-*`, project name in one config) so a rename is a one-hour change.
