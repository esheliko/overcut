# 0014 Governance and funding
**Status**: **open: decide by M3** (before the public beta invites contributors)

**Questions.** Who decides what (BDFL, steering group, foundation host)? How are donations held (fiscal host such as Open Collective, a nonprofit umbrella)? What is the written commitment against feature gating and for user privacy? Code of conduct, contribution guide, security reporting address, release ownership.

**Recommendation.** Start as owner-led with a published `GOVERNANCE.md` containing the "no gating, no tracking, no account" commitments; join a fiscal host before accepting money; adopt DCO; move to a small steering group when there are three regular maintainers.
